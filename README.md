# KazOlymp

Бесплатный архив олимпиадных задач: kazolymp.github.io

## Файлы
- `index.html` — дизайн и логика сайта (обычно не трогаем)
- `data.js` — всё наполнение: предметы, олимпиады, темы, задачи, результаты, материалы, календарь, новости
- `images/news/` — фото для новостей
- `pdf/` — PDF заданий и решений

## Как добавить задачу
В `data.js` в список `PROBLEMS` добавить запись:

```js
{id:"p-chem-resp-2025-1", subj:"chemistry", title:"Название", olymp:"Республиканская олимпиада",
 year:2025, grade:10, topic:"Равновесие", diff:3,
 text:`<p>Условие</p>`,
 answer:{type:"num", value:1.6, tol:0.02, unit:"моль/л"},   // или {type:"text", value:["C3H6"]}
 solution:`<p>Решение</p>`},
```

`id` должен быть уникальным. Тема (`topic`) — одна из тем в `TOPICS`.
